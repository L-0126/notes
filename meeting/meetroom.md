# 会议室午间余席速查

前台按日期和轮次抄录座位数与已留席位，运行后可以逐行回看余量。每行代表某一天的半小时，相邻轮次分别登记。

## 使用方法

需要 Python 3，无须安装其他包。直接运行内置四行示例，或者传入自己的 CSV 文件。

```shell
python example.py
python example.py capacity.csv
```

## 清单格式

首行按顺序写 时段, 座位数, 已留座。后两列填写非负整数，后一列最多等于前一列。文件使用 UTF-8 编码，可以直接读带 BOM 的表格导出文件。

## 输出举例

第一行“周二12:10”的余量为 3 席。四行合计剩余 6 席。程序按原行顺序显示时段，便于和纸面登记逐项核对。

如果遇到表头不一致或数量超出范围，控制台会提示错误。先修改提示的行，再重新运行即可。
